## 🎨 Brand Colors

### ADVIJR Color Scheme
- **Primary Blue**: `#0052CC`
- **Light Blue**: `#0066FF`
- **Secondary Orange**: `#FF8C42`

### Where Colors Are Used
- **Blue**: Headers, buttons, active states, primary actions
- **Orange**: Accents, ratings, highlights
- **Gradients**: Blue to light blue for headers

### How to Change
Edit `MyAppName/constants/Colors.ts`:
```typescript
export const Colors = {
  primary: '#0052CC',        // Your primary color
  secondary: '#FF8C42',      // Your accent color
  // ... rest of colors
};
```
