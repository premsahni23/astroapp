## 🚨 Common Issues

### Can't Run Backend
**Problem**: Port 8080 in use  
**Solution**: Kill process or change port in `application.properties`

### Can't Run Frontend
**Problem**: Module not found  
**Solution**: `cd MyAppName && rm -rf node_modules && npm install`

### Can't Push to GitHub
**Problem**: Authentication failed  
**Solution**: Use Personal Access Token (not password)  
Get token: https://github.com/settings/tokens

### Database Connection Failed
**Problem**: Can't connect to MariaDB  
**Solution**: Check MariaDB is running, verify credentials in `application.properties`
