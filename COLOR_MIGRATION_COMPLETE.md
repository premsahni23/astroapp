## Color Usage Guidelines

### When to Use Blue (#0052CC)
- Primary buttons and CTAs
- Active tab indicators
- Header backgrounds (with gradient to #0066FF)
- Primary icons and badges
- Loading indicators
- Active states

### When to Use Orange (#FF8C42)
- Star ratings
- Secondary accents
- Special highlights
- Complementary elements

### Gradients
- **Primary Gradient**: `['#0052CC', '#0066FF']` - Used for headers and primary elements
- **Secondary Gradient**: `['#FF8C42', '#FFA05C']` - Used for special accents
